# Add this project to an existing repository

This project is designed to live at `agent-skills/` within the existing `Advanced-Bioinformatics` repository so the existing top-level learning roadmap and CC BY 4.0 license remain untouched. To enable CI in that parent repository, use the `.github/workflows/agent-skills-ci.yml` file at the root of the drop-in archive in the parent repo's `.github/workflows/` directory. The standalone `.github/workflows/test.yml` inside this project is for using the project as its own repository.

A short root README addition is supplied as `README-AGENT-SKILLS-SNIPPET.md` alongside the project archive. It is intentionally a snippet rather than a replacement README.
